# 📂 Prospect Theory Agent: Repository Guide

This document explains the purpose of every file in this repository, categorized by its function in the trading system.

## 🟢 1. Live Trading System (The "Engine")
These are the files you use every week to generate your trading signals.

*   **`weekly_trade.sh`**: **The Master Switch**. This is the shell script you run (`./weekly_trade.sh`). It orchestrates the entire process: fetching data, running the model, and printing your action plan.
*   **`fetch_qqq.py`**: **The Data Fetcher**. Downloads the latest market data (QQQ price, Treasury yields, VIX) from Yahoo Finance and calculates technical indicators (RSI, MACD). It saves this to `qqq_data_60days.csv`.
*   **`get_recommendation.py`**: **The Decision Maker**. Loads the latest data and the tuned model, then outputs the BUY/SELL/HOLD signal and confidence score.
*   **`prospect_theory_agent.py`**: **The Brain Anatomy**. Defines the neural network architecture (Prospect Theory layers, Utility function, etc.). Both training and live scripts import this to build the model.
*   **`prospect_theory_model_tuned.pth`**: **The Trained Brain**. The file containing the "weights" (learned patterns) of your currently active, tuned model.
*   **`trade_log.csv`**: **The Journal**. Automatically records every signal generated by the system for your records.
*   **`qqq_data_60days.csv`**: **The Fuel**. A temporary file containing the most recent 90 days of market data, used as input for the live model.

---

## 🔴 2. Model Training (The "Gym")
These files were used to teach the model how to trade.

*   **`train_tuned_model.py`**: **The Trainer**. The script used to train your current model. It feeds historical data to the agent, lets it practice trading, and updates its brain based on rewards.
*   **`qqq_market_data.csv`**: **The Textbook**. The massive historical dataset (10+ years of QQQ data) used for training.
*   **`prospect_theory_model.pth`**: **The Old Brain**. The previous, less-tuned version of the model. Kept as a backup.

---

## 🔵 3. Analysis & Backtesting (The "Report Card")
These files are for verifying performance and researching strategies. You don't need them for live trading.

*   **`backtest_weekly_full.py`**: Runs the "Non-Overlapping Weekly" backtest on the full 10-year history.
*   **`analyze_significance.py`**: Performs statistical tests (Sharpe Ratio, T-test) to check if the model's performance is luck or skill.
*   **`calculate_pnl.py`**: The script used to reconstruct your personal PnL from Nov 21.
*   **`analyze_60day_weekly.py`**: Analyzes performance on just the last 60 days.
*   **`backtest_full_history.py`**: Runs a daily trading backtest on the full history.
*   **`analyze_advanced_strategies.py`**: Research script for testing different thresholds and holding periods.
*   **`*.csv` (Results)**: `weekly_full_backtest.csv`, `full_backtest_results.csv`, etc. contain the raw output data from these tests.
*   **`*.png` (Plots)**: `tuned_results.png`, `results.png`, etc. are graphs generated during training or analysis.
